# 루트로그 (RouteLog)

여행 중 스팟마다 올린 포스팅이 시간순 **여행가이드**가 되고, 공유받은 사람이 그 가이드를 **따라가거나 포크(리믹스)** 해서 루트·쇼핑·가게를 더해 다시 공유하는 여행 SNS 프로토타입입니다.

배포: https://hbyim.github.io/routejourney/

## 주요 기능

- **스팟 포스팅**: 사진, 한 줄 기록, 별점, 쓴 돈, 위치(지도 탭 또는 현재 위치)
- **여행 모드**: 여행을 시작하면 이후 포스팅이 날짜별(Day 1, Day 2…) 가이드에 자동으로 쌓임
- **가이드 상세**: 일차별 타임라인 + 지도 동선, 지출 합계
- **포크**: 남의 가이드를 복사해 스팟 추가·삭제·순서·일차 변경, 원본 출처와 "포크에서 추가" 표시
- **계보**: 원본에서 갈라져 나온 파생 가이드 트리
- **따라가기**: 체크리스트로 방문 표시, 다음 스팟 길찾기
- **공유 링크**: 가이드 전체를 압축해 URL에 담아 앱·서버 없이 전달 (사진 제외)
- **탐색**: 검색, 종류 필터, 인기·포크·최신 정렬, 스팟 지도

## 구조

서버 없는 정적 웹앱입니다. 데이터는 브라우저 `localStorage`에 저장되고, 첫 실행 때 도쿄 샘플 가이드 3개가 들어갑니다.

```
index.html        앱 셸 (반응형: 모바일 하단 탭, 태블릿·데스크톱 사이드 내비)
css/style.css     스타일 (다크 모드 지원)
js/seed.js        도쿄 샘플 데이터
js/app.js         라우터, 화면, 데이터 모델, 공유 링크
vendor/leaflet    지도 라이브러리 (Leaflet 1.9.4, OpenStreetMap 타일)
```

로컬 실행: `python3 -m http.server` 후 http://localhost:8000
